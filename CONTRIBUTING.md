# Contributing to EchoFlow

We welcome contributions to **EchoFlow**! This project was created as an open-source contribution for the Amazon Developer Hackathon 2026.

## How to Contribute
1. **Fork the repository** on GitHub.
2. **Create a feature branch**: `git checkout -b feature/amazing-new-mcp-tool`.
3. **Make your changes** and add unit tests in `server/test/`.
4. **Ensure tests pass**: `npm test`.
5. **Commit your changes**: `git commit -m 'Add support for Ring camera MCP tool'`.
6. **Push to your branch**: `git push origin feature/amazing-new-mcp-tool`.
7. **Open a Pull Request**.

## Code Style
- Written in clean TypeScript with strict mode enabled.
- Follow MCP Specification `2025-11-25+` conventions.
- Format with standard prettier rules.
